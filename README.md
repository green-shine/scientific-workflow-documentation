# Statistical Analysis of Workflow Documentation

This repository contains the Python code and questionnaire used in the bachelor's thesis *"Exploring Agentic Pipelines for Automated Documentation Generation"*.

## Contents

- `analysis.ipynb` – Python code for the statistical analysis and visualizations reported in the thesis
- `requirements.txt` – Python dependencies required to run the analysis
- `questionnaire/` – questionnaire used in the user study
  - `limesurvey_survey.lss` – LimeSurvey survey definition
  - `questionnaire.html` – human-readable version of the questionnaire

## Reproducibility

The notebook can be executed from top to bottom to reproduce the statistical analyses and visualizations reported in the thesis.

The anonymized analysis data required as input for the `analysis.ipynb` notebook are provided separately in the thesis appendix.
